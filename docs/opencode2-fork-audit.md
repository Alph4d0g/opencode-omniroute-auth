# Проверка совместимости с OpenCode 2

Дата: 2026-11-01.

Проверен запрошенный форк:
https://github.com/Rahulsharma0810/opencode-omniroute-auth,
ветка `main`, исходный коммит `b42f567b5cfc0bda56d663d843b47e4bf82cd3f2`, версия `2.1.3`.
Форк уже содержит отдельные жизненные циклы V1/V2 в объекте `{ id, setup, server }`.
Исправления сохраняют эту архитектуру и не меняют номер версии.

## Исправления

- `src/plugin-v2.ts`: повторное определение native credentials после события
  `integration.updated` устраняет задержку обнаружения сохранённого аккаунта при старте.
  OpenCode применяет регистрацию интеграций пакетно после завершения `setup()`.
- Смена аккаунта запускает последовательное обновление моделей. Результат запроса от
  предыдущего аккаунта отбрасывается; модели привязаны к `sourceConnection`.
- Удаление native credentials очищает ключ и модели аккаунта. Legacy/env fallback
  больше не восстанавливает отозванный ключ после перехода на управление аккаунтом в V2.
- Завершённое после `cleanup()` обнаружение не публикует модели и не перезагружает provider.
- HTTP hooks проверяют origin и границу пути настроенного OmniRoute API. Изменённое
  JSON-тело отправляется без прежнего `content-length`.
- `src/discovery.ts`, `src/models.ts`, `src/omniroute-combos.ts`: заголовки шлюза
  передаются при discovery моделей/комбо; кеши разделены по endpoint, ключу и заголовкам.
  Кеш моделей также учитывает `hideModelAliases`, а комбо используют актуальный ключ.
- `dist/` пересобран, поскольку форк распространяет готовый код для установки из Git.

## Границы проверки

Runtime-проверка использует локальный mock API. Реальный удалённый OmniRoute и upstream
провайдеры при первоначальном аудите не проверялись. Режим Responses и запуск V1 покрыты
тестами исходного кода, но отдельный запуск их CLI не выполнялся. Результаты последующей
установки приведены ниже. Публикация npm и создание релиза не выполнялись.

## Подключение локальной версии

После первоначального аудита выполнена установка на OpenCode Desktop **2.2.4**.
Плагин получил статус `active`; через реальный локальный OmniRoute обнаружено
**670 моделей** в режиме `responses`. Генерация через реальные upstream-провайдеры
при установке не выполнялась. Изолированный CLI smoke test дополнительно пройден
на версии **2.2.4**.

После сборки укажите эту рабочую копию в конфигурации OpenCode 2:

```json
{
  "plugins": [
    {
      "package": "C:/path/to/opencode-omniroute-auth",
      "options": {
        "baseURL": "http://localhost:20128/v1"
      }
    }
  ]
}
```

Замените `baseURL` на адрес своего OmniRoute и подключите ключ через `/connect omniroute`
или `OMNIROUTE_API_KEY`. Для установки из GitHub используйте инструкции в README.
